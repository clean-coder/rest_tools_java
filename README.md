# Ollama REST with Tools Support
* Sample code in Java which shows how to access Ollama via REST with and without tools support.
* We want to ask Ollama what we should take with us for a short trip to Paris.
  * WeatherNoTools.java makes a request to Ollama without context.
  * WeatherWithTools.java also makes a request to Ollama, but this time with context and tools support.
* The original code is written in Python and can be found at https://github.com/clean-coder/rest_tools_py. The code is then converted to Java using Claude AI.
